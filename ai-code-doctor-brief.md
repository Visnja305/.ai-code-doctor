# Capstone Brief

## Project Name
AI-code-doctor

## Problem It Solves
Inspects the code snippets or the full GitHub repositories

## Who Uses It
Software developers

## Feature 1-Code Inspector Agent
What it does: Analyzes the code and determines its overall health.
What it outputs: Detects bugs and potential errors, identifies inefficient code, finds security vulnerabilities, detects bad coding practices, checks whether the code follows language conventions and rates the code quality from 1-10.

## Feature 2-Refactor Agent
What it does: Improves the code without changing its functionality.
What it outputs: Rewrites inefficient code, removes duplication, simplifies logic, improves readability, applies modern best practices and suggests better architectures and design patters.

## Feature 3-Review Agent
What it does: Explains why the change matters.
What it outputs: Compares the original and improved code, explains every change in plain English, estimates performance gains, suggests additional improvements and generates a final report.

## Feature 4-Repo Doctor
What it does: Analyzes a GitHub repo-full-stack code
What it outputs: A structured report with a plain-language summary of the problem, a "do this first" callout for the single most-blocking fix, and a prioritized list of issues each showing what's wrong, why it's happening, and the exact corrected code/config to fix it.

## Tools From This Course It Uses
 Firebase, PromptAnything, Google MCP, Gmail, Sheets, agents, etc.
